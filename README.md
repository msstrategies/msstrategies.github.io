## What this is

The GitHub Pages source for the MSStrategies portfolio: a single static page, no framework, no build step. It covers the two systems that show how I think about reliable AI (deterministic core, LLM at the edge), two years of sitting with the customer as the reliability layer between a messy problem and shipped software, and the toolbox behind it.

## Run it locally

```bash
git clone https://github.com/msstrategies/msstrategies.github.io.git
cd msstrategies.github.io
open index.html
```

No dependencies, no server required. GitHub Pages serves `index.html` directly from `main`.
